## 아이디어: 회원가입 경로 여러 개 (2026-10-26 메모, 미확정)

다른 앱처럼 가입 첫 화면에서 유형을 고르게 한다: **학생 / 학생회·교내 기관 / 외부 기업**

| 유형 | 인증 방법 | 할 수 있는 것 |
| --- | --- | --- |
| 학생 | 학교 이메일 인증번호 (지금 방식) | 응답·마일리지 적립·설문 등록·열람 |
| 학생회·교내 기관 | 학교 이메일 인증 + 단체 정보 입력 → **운영자 승인** | 설문 등록, 결과 확인 (응답·적립은 안 함) |
| 외부 기업 | 일반 이메일 인증 + 회사 정보 입력 → **운영자 승인** | 설문 등록, 결과 확인 (응답·적립은 안 함) |

개발 쪽 개선안:
- **표는 하나로**: `profiles`에 `account_type`(학생/기관/기업)과 `approval_status`(대기/승인/거절) 칸을 둔다. 유형마다 표를 따로 만들지 않는다
- **유형·승인 상태는 사용자가 못 바꾸게** RLS로 막는다. 승인은 운영자만 (대시보드에서 직접 바꾸거나 운영자 전용 서버 함수)
- **응답은 학생만**: 기관·기업은 응답·마일리지 적립 불가. "인증된 대학생 표본"이라는 서비스 가치를 지키고, 기업 계정으로 포인트를 모으는 악용도 막는다
- **승인 전에는** 로그인은 되지만 "승인 대기 중" 화면만 보여 준다
- **단계적으로**: MVP(1~2단계)는 학생 가입만 앱에 만들고, 기관·기업 계정은 운영자가 대시보드에서 직접 만들어 준다. 가입 유형 선택 화면은 시간이 남으면 추가. 이렇게 해도 DB에 `account_type`이 처음부터 있으니 나중에 화면만 붙이면 된다
