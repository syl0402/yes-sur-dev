# 옛썰 계정 삭제 안내

옛썰(Yes Sur) 계정과 데이터를 삭제하는 방법입니다.

## 앱에서 삭제하기
1. 옛썰 앱에 로그인합니다.
2. 아래 탭 **마이**에서 이름을 눌러 **내 정보**로 들어갑니다.
3. 맨 아래 **회원 탈퇴**를 누릅니다.
4. 안내를 확인하고 현재 비밀번호를 입력한 뒤 **탈퇴하기**를 누릅니다.

탈퇴는 바로 처리됩니다.

## 앱을 쓸 수 없을 때
아래 메일로 **가입한 메일 주소**와 함께 계정 삭제를 요청해 주세요. 본인 확인 후 7일 안에 삭제합니다.

- 메일: yessur.team@gmail.com
- 제목 예시: 옛썰 계정 삭제 요청

## 삭제되는 정보
- 계정과 회원정보 (메일, 닉네임, 학교, 전공 계열, 과정, 입학년도, 성별, 출생연도)
- 포인트와 포인트 내역, 신고 기록
- "나만 보기"로 올린 설문과 그 응답

## 남는 정보 (개인을 알아볼 수 없는 상태)
- 다른 설문에 남긴 응답: 회원과의 연결을 끊고, 계열·학년·성별·나이대 구간만 통계에 남습니다.
- 공개로 올린 설문과 그 결과: 데이터 허브에 남습니다. 개인 설문은 원래처럼 "개인"으로만 표시됩니다.
- 웰컴 포인트 중복 지급을 막기 위해, 메일 주소를 되돌릴 수 없게 바꾼 값(해시)만 보관합니다.
