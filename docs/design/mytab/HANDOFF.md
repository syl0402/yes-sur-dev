# 옛썰 마이 탭 개선 – 개발 핸드오프

`designs/` 의 `.dc.html` 은 디자인 시안 원본이에요. 레이아웃·색·문구·인터랙션 참고용이고 그대로 실행되는 코드는 아니에요. 우리 앱 스택과 기존 컴포넌트에 맞게 다시 구현해 주세요.
게시글 제목·숫자·날짜는 모두 예시예요. 실제 데이터로 연결해 주세요.
화면 오른쪽 위에 떠 있던 파란 톱니 버튼은 개발용 도구로 보고 시안에서 뺐어요.

## 0. 공통 스타일
| 토큰 | 값 | 쓰임 |
|---|---|---|
| 바탕 | `#FCFCFC` | 모든 화면 배경 (기존 앱과 같음) |
| 카드 | 흰색 `#FFFFFF` + 테두리 `1px #ECEEF3` + 그림자 `0 2px 10px rgba(32,42,64,0.04)`, radius 22 | 기존 앱 카드와 같은 느낌 |
| 회색 상자 | `#F7F8FC` / `#EFF1F7` | 정보 묶음, 탭 바탕 |
| Blue 50 / 100 / 500 / 600 | `#F1F4FF` / `#E3E9FF` / `#3157D5` / `#2949B5` | 강조, 보조 버튼, 주 버튼 |
| Lime 100 / 500 / 800 | `#F0F8D5` / `#A3EA16` / `#506D23` | 친구 초대, 진행 중 배지, 포인트 획득 |
| 경고 | `#FEF6E7` / `#93370D` | 응답 없이 마감 |
| 글자 | `#202A40` 본문 / `#545E73` 보조 | |

- 입력 칸만 테두리(`#E2E5EE`) 유지
- 탭 안에 탭을 또 두지 않기
- **칩은 최소로**: 상태 칩은 '진행 중 / 마감'만. 나머지 상태는 글자로, 보조 행동은 글자 링크(예: '홍보하기 ›')
- 모든 애니메이션은 `prefers-reduced-motion: reduce` 일 때 끔

## ① 마이 홈 (`Main.dc.html`)
위에서부터
1. 헤더 "마이" + 오른쪽 톱니 → ⑦ 내 정보
2. 프로필 줄 (아바타, 닉네임, 학교·계열) → ⑦
3. **포인트 카드 (기존 디자인 유지)**: Blue 500 바탕, 오른쪽 아래 둥근 고리 장식(반투명 흰 테두리 원), "내 포인트", 큰 숫자, 라임 링크 "포인트는 어떻게 모으고 쓰나요? ›"(→⑧). 숫자·오른쪽 위 "내역 보기 ›" → ③
4. 라임 배너 "친구 초대하면 300P · 친구도 200P" → ④
5. **카테고리 탭** (회색 `#EFF1F7` 바탕 안 흰 알약이 미끄러짐): 내 설문 / 내 데이터 / 커뮤니티
6. 요약 숫자 한 줄 (배경 없음, 숫자 굵은 검정, 칸 사이 회색 세로선): 운영 중·받은 응답 / 응답·스크랩·열람 / 글·댓글·참여
7. 섹션 제목 줄: 왼쪽 "진행 중인 설문 / 최근 본 데이터 / 최근 활동", 오른쪽 "전체 보기 ›"(→ ②, ⑤, ⑥)
8. 내용
   - 내 설문: 기존 카드 그대로 ("진행 중" 칩 + "등록 날짜", 큰 제목, "응답 진행률 n / 목표명 · %", 진행 바, 아래 공개 범위 + 파란 "결과 보기" 버튼). **응답 0명이면 버튼 대신 글자 링크 "홍보하기 ›"**. 카드 아래 연파랑 "+ 새 설문 등록" 큰 버튼
   - 내 데이터 / 커뮤니티: 흰 카드 안 목록 (제목 + 한 줄 정보 + 화살표), 칩 없음
9. 도움: 의견 보내기(새 답변 수), 사용 안내 다시 보기 / 맨 아래 작은 글씨 "기업·학생회라면 제휴·광고 문의"

애니메이션 (모두 0.3~0.6초)
- 탭 바꿀 때: 흰 알약 배경 슬라이드, 아래 내용 페이드업
- 진행 바: 0에서 현재 값까지 채움
- **포인트가 바뀌었을 때만**: 숫자 카운트업 + 라임 칩 "+nP 들어왔어요" 약 2초 후 사라짐. 평소엔 움직이지 않음
- 카드·버튼 누르면 scale(.97)

## ② 내 설문 전체 (`MySurveys.dc.html`)
- 요약 3칸: 운영 중 / 받은 응답 / 결과 열람
- 탭 한 줄: 진행 중 n / 마감 n
- 카드: 마이 홈과 같은 기존 카드. 응답 있으면 파란 "결과 보기", 0명이면 글자 링크 "홍보하기 ›"
- 마감 카드: 데이터 탭에 공개 중이면 연파랑 안내 상자 "데이터 탭 공개 중 · 열람 n회 · 열람마다 +40P". 응답 없이 마감은 회색 글자 "응답 없이 마감 · 등록비 n명분 환불됨" + 글자 링크 "다시 올리기 ›"

## ③ 포인트 내역 (`Points.dc.html`)
- 지금 포인트, 이번 달 모은 / 쓴
- 필터 칩: 전체 / 모은 / 쓴
- 날짜별 묶음, 줄마다 종류 아이콘 · 이름 · 상세(설문 제목, 시간) · 금액 (+ 파랑, - 검정)
- **"기타" 같은 이름 금지**: 실제 사유로 (예: 웰컴 미션 n일차, 오늘의 질문 7일 연속, 설문 등록 "목표 10명 × 15P")
- 맨 아래 "포인트는 어떻게 모으나요?" → ⑧

## ④ 친구 초대 (`Invite.dc.html`)
- 파란 카드: 내 코드, 코드 복사 / 공유하기
- 초대한 친구 n명 · 받은 포인트
- **신규: "친구한테 코드 받았어요" 입력칸** (가입 7일 안에만 보임, 남은 일수 표시, 한 번만)
- 안내: 7일 안 입력, 한 달 10명까지, 내 코드는 입력 불가

## ⑤ 내 데이터 (`MyData.dc.html`)
- 탭: 응답한 n / 스크랩 n / 열람한 n, 탭마다 안내 한 줄
- 줄: 제목 + 한 줄 정보("카테고리 · 마감·응답 수 · 상태") + 화살표. **칩 없음**. 결과가 공개된 것만 오른쪽에 파란 글자 "결과 보기"

## ⑥ 내 커뮤니티 활동 (`MyPosts.dc.html`, 기존 "내가 쓴 글")
- 요약: 참여 수 / 오늘의 질문 연속 / 커뮤니티로 받은 포인트
- 탭: 글 / 댓글 / **참여(신규)**
  - 글: 종류 배지, 제목, 참여·댓글 수. 밸런스 글은 결과 막대
  - 댓글: 댓글 내용 + "종류 · 글 제목 · 날짜"
  - 참여: 내가 투표한 밸런스·나만 그래?·골라 줘·월드컵·오늘의 질문 + 내가 고른 답 칩
- "익명으로 쓴 글·댓글도 여기서는 나에게만 보여요"

## ⑦ 내 정보 (`Profile.dc.html`)
**기존 화면과 똑같이** + 두 가지만 추가
- 동그란 흰 뒤로 버튼, 가운데 제목 "내 정보"
- 큰 아바타 + "yessur님" + 학교 이름 옆 **"학교 메일 인증" 라임 배지(신규)**
- 회원정보 회색 상자 + "회원정보를 고치려면 '의견 보내기'로 문의해 주세요."
- 계정: 닉네임 바꾸기, 비밀번호 변경, 의견 보내기
- 알림: 오늘의 질문 알림, 웰컴 미션 알림, **내 설문 소식(신규: 목표 인원 도달, 마감, 결과 열람)**
- 안내·약관: 사용 안내 다시 보기, 포인트 안내, 이용약관, 개인정보처리방침
- 로그아웃, 회원 탈퇴(밑줄 작은 글씨)

## ⑧ 포인트 안내 (`PointGuide.dc.html`)
- **연파랑 카드**(`#E3E9FF`, 진한 파랑은 눈이 아파서 X): "응답 2번 = 내 설문 응답 1명" + 흰 상자 안 **"지금 nP면 3분 이내 설문에 n명을 모을 수 있어요"** (내 포인트 ÷ 15P)
- 모으기 / 쓰기 목록 (아이콘 + 이름 + 조건 + 금액), 설문 길이별 표, 알아 둘 것
- 금액은 기존 앱 정책 그대로

## ⑨ 의견 보내기 (`Feedback.dc.html`)
- 종류 칩 (고른 칩 파랑): 버그·오류 / 불편해요 / 바라는 기능 / 기타. 종류마다 placeholder 예시가 바뀜
- 내용 + **화면 캡처 첨부(신규)** + 글자 수
- 기기 종류·앱 버전 자동 첨부 안내
- 내가 보낸 의견: 상태 배지 색 구분 (반영 완료 라임 / 답변 완료 파랑 / 확인 중 회색)

## ⑩ 제휴·광고 문의 (`Partner.dc.html`)
- "어떤 곳인가요?" 칩: 기업·브랜드 / 광고 대행사 / 학생회·동아리 / 기타 → 첫 입력칸 이름·placeholder가 바뀜
- "무엇을 하고 싶나요?" 칩 (여러 개): 설문 의뢰 / 광고·배너 / 이벤트 제휴
- 입력: 이름, 이메일, 휴대폰(선택), 문의 내용
- 개인정보 동의 체크 + 한 줄 요약 + 전문 링크 (보관 기간 문구는 실제 방침으로)
- 내가 보낸 문의 + 상태
- 기존 "옛썰을 어디서 알게 됐나요?"는 필요하면 선택 항목으로 맨 아래

## ⑪ 사이드 메뉴 (`SideMenu.dc.html`)
- 위: 로고, 닫기, 프로필 카드 (앱 카드 스타일: 흰 바탕 + 연한 테두리, 아바타 + "yessur님" + "내 포인트 nP") → 마이
- 메뉴: **홈**, 검색, 옛썰 소개, 의견 보내기, 제휴·광고 문의
- 아래 작은 링크: 이용약관 · 개인정보처리방침 · 버전
- 로그아웃은 ⑦로 이동
