# 옛썰 데이터 허브 (결과 화면 · 결과 카드) – 개발 핸드오프

범위: 데이터 허브 **목록 화면은 제외**. 열람 전 미리보기, 결과 보기, 공유 시트, 결과 카드 이미지 2종.

`designs/` 의 `.dc.html` 은 디자인 시안 원본이에요. 레이아웃·색·문구·인터랙션 참고용이고 그대로 실행되는 코드는 아니에요. 우리 앱 스택과 기존 컴포넌트에 맞게 다시 구현해 주세요.
시안 속 이미지 경로(`/_blob/...`)는 캔버스 전용이라 `assets/cheer.png` 를 쓰면 돼요.
수치는 기존 화면의 예시 데이터(대학생 아르바이트 경험, 63명)이고, 그룹별 수치와 Q3 제목은 시안용 예시예요.

## 0. 디자인 토큰

차트 공통 규칙
- 1위(최댓값) 막대만 Blue 500, 나머지는 연한 색 (선택형) 또는 Natural 300
- 값이 큰 순서로 정렬 (그룹 비교)
- 퍼센트는 굵게, 인원(n명)은 작게 회색
- 10명 미만 그룹은 흐리게 + "해석에 주의해 주세요"

## ① 열람 전 미리보기 (`Preview.dc.html`) — 신규
- 헤더: 뒤로 / 스크랩
- 태그(카테고리, ✓ 신뢰도 높음), 제목, 설명
- 요약 3칸: 응답 n명 / 문항 n개 / 조사 기간
- 핵심 인사이트: 첫 번째만 공개, 나머지는 흐림(blur) + 자물쇠
- "이런 문항의 결과를 볼 수 있어요": 문항 번호·제목·답변 방식 목록, 결과는 잠금 아이콘
- "+ 응답자 구성(성별·나이대·학년·계열)과 조사 정보"
- 하단: "한 번 열면 계속 볼 수 있어요 · 내 포인트 nP" + "nP로 전체 결과 보기"
- 이미 열람했거나 내 설문이면 이 화면 없이 바로 ②로

## ② 결과 보기 (`Detail.dc.html`)
- 헤더: 뒤로 / "설문 결과" / 스크랩
- 태그, 제목, "작성자 · 응답 n명 · 마감일"
- 핵심 인사이트 카드 (기존 유지)
- 3탭 세그먼트: 문항별 결과 / 응답자 / 조사 정보

### 문항별 결과
- "나눠 보기" 칩: **전체 · 성별 · 나이대 · 학년 · 계열** (화면 전체 문항에 같이 적용)
- 전체: 보기별 가로 막대, 1위만 파랑
- 그룹 선택 시 (누적 막대 아님):
  1. 보기 칩이 나옴 (예: 하고 있어요 / 안 하지만 해 봤어요 / 안 해 봤어요), 기본값은 인사이트와 관련된 보기
  2. "'보기'라고 답한 비율"을 그룹별 가로 막대로, 큰 순서 정렬
  3. 최고 그룹 진한 파랑·굵게, 최저 그룹 Blue 300, 나머지 Blue 200
  4. 그룹명 아래 인원, 맨 아래 점선 + "전체 평균 n%"
  5. 10명 미만 그룹은 흐리게 + 경고 문구
- 여러 개 고르기: "여러 개 고를 수 있어서 합이 100%를 넘을 수 있어요"
- 5점 척도: 큰 평균 숫자 + 1~5 세로 막대(최빈값만 파랑) + 양 끝 라벨

### 응답자
- 상단 요약 "가장 많이 답한 사람: 여성 · 21~23세 · 3~4학년 · 사회/자연 계열"
- 성별 / 학년 / 계열(+나이대) 카드별 가로 막대 (도넛 대신)

### 조사 정보
- "✓ 신뢰도 높음인 이유" 박스 (기준은 실제 정책으로 교체: 시안은 응답 30명↑, 확인 문항 통과율 90%↑ 예시)
- 유효 응답 / 평균 응답 시간 / 조사 기간 / 대상
- 확인 문항을 틀려 제외한 응답 수 안내
- 이 설문 신고하기

### 하단 고정
- [출처] 아이콘 버튼 · [공유] 아이콘 버튼 · [집계 CSV 받기] 메인 버튼
- 공유 → ③ 공유 시트

## ③ 공유 시트 (`ShareSheet.dc.html`)
- 바텀시트 "결과 카드로 공유"
- 세그먼트: 인사이트 카드 / 문항 카드
- 미리보기 (실제 카드 축소본)
- 문항 카드일 때 문항 선택 칩 (Q1, Q2, …)
- 액션 4개: 스토리 공유 / 이미지 저장 / 링크 복사 / 더보기(OS 공유)

## ④ 결과 카드 이미지
### 인사이트 카드 — 스토리 9:16 (`CardStory.dc.html`, 540×960 시안 → **1080×1920 저장**)
- 파란 배경 + 장식 원 2개
- 상단: "옛썰" + 라임 배지 "대학생 데이터" / 오른쪽 "응답 n명"
- "Q. 문항 제목" (작게) → 인사이트 한 줄 (46px 굵게, 숫자 하나만 라임)
- 흰 카드: 근거 차트 1개 (그룹별 비율, 정렬, 1위만 파랑) + "전체 평균"
- 하단: 캐릭터 + "너는 어때? 옛썰에서 답하고 결과 보기" + "옛썰 데이터 허브 · 조사 기간"
- 인사이트 문구·차트는 결과 화면의 핵심 인사이트 1번에서 자동 생성

### 문항 카드 — 정사각 1:1 (`CardSquare.dc.html`, 540×540 시안 → **1080×1080 저장**)
- 연파랑 배경, 상단 "대학생 n명에게 물었어요" 배지 + "옛썰"
- 문항 제목 30px
- 보기별 막대 최대 3~4개, 1위만 파랑·큰 숫자
- 하단: 출처·기간·응답 수 + 캐릭터
- 5점 척도는 3묶음으로 요약: 그래요(4~5점) / 보통(3점) / 아니에요(1~2점)
- 보기가 5개 넘으면 상위 4개 + "그 외"

공통: 응답 수·조사 기간·출처를 항상 넣기, 10명 미만 그룹은 카드 차트에서 제외.

## 확인 필요
1. 열람 비용 (시안은 40P 예시)과 내 설문·이미 열람한 설문 무료 여부
2. 신뢰도 높음 기준
3. 인사이트 자동 생성 규칙 (어떤 차이를 '가장 크다'로 볼지)
4. 스토리 공유: 인스타그램 스토리 공유 API 연동 여부, 안 되면 이미지 저장 후 안내
