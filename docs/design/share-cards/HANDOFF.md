# 옛썰 커뮤니티 결과 공유 이미지 – 개발 핸드오프

링크(딥링크)가 아직 없어서 **이미지로 공유**해요. 카톡·인스타 스토리에 바로 올라가게.
`designs/` 의 `.dc.html` 은 디자인 참고용이에요. 우리 앱 스택으로 다시 만들어 주세요.
시안 속 캐릭터 이미지(`/_blob/...`)는 `assets/cheer.png` 를 쓰면 돼요. 수치·문구는 예시예요.

## 틀 3개
| 파일 | 크기(시안 → 실제 저장) | 쓰는 곳 |
|---|---|---|
| `ShareBalance.dc.html` | 540×540 → **1080×1080** | 밸런스, 나만 그래?(나도 그래 vs 나는 아니야), 보기 2개인 오늘의 질문 |
| `SharePick.dc.html` | 540×540 → **1080×1080** | 골라 줘, 보기 3개 이상인 오늘의 질문 |
| `ShareWorldcup.dc.html` | 540×960 → **1080×1920** (스토리) | 월드컵 내 결과 |

실제 저장은 시안의 2배 크기로 (글자·여백 모두 2배).

## 공통
- 바탕 Blue 500 `#3157D5`, 오른쪽 위(또는 왼쪽) 연한 원 장식 `#6F8BEB` 투명도 .35~.45
- 맨 위 라임 배지(`#A3EA16` / 글자 `#202A40`): 종류 이름 + "n명이 골랐어요"
- 맨 아래: "옛썰" 로고 글자 + 한 줄 문구 + 오른쪽 아래 캐릭터
- 폰트 Pretendard

## 밸런스 (`ShareBalance`)
- 질문, "A파 / B파" 라벨, 큰 줄다리기 막대 (A 흰색 + 파란 글자, B 라임), 경계에 VS 배지
- "나는 ○○파" 칩 + "우리 편이 이기는 중 / 밀리는 중 / 팽팽해요!"
- 투표 안 한 사람이 공유하면 "나는 ○○파" 칩 없이
- 문구: "너는 어느 파? 옛썰에서 골라 봐"

## 골라 줘 (`SharePick`)
- 보기 전부 막대 (최대 5개), 보기 순서 그대로
- 1위: 흰 막대 + 라임 "1위" 칩 / 내 선택: 연파랑 `#C7D2FF` 막대 + 남색 "내 선택" 칩 / 나머지: 반투명 흰 막대
- 문구: 내가 1위 골랐으면 "나도 1위 골랐어! 너는?", 아니면 "나만 다른 거 골랐나? 너는?"

## 월드컵 (`ShareWorldcup`)
- 제목, 흰 카드 "나의 우승" + 트로피 + 내 1위 크게
- 칩: "모두의 1위와 같아요!" / "모두의 순위로는 n위" / 순위에 없으면 "나만 아는 1위"
- "모두의 순위 · n명 참여" 1~3위 막대 (1위 동그라미 라임, 내 1위 막대 라임)
- 문구: "너의 1위는? 옛썰에서 해 봐"

## 공유 버튼 위치
- 밸런스·나만 그래?·골라 줘 상세: 오른쪽 위 공유 아이콘
- 월드컵 결과: 하단 "결과 공유"
- 누르면 이미지를 만들어 OS 공유 시트(카톡, 인스타 스토리, 저장)로
