## 3. 규칙

- 가입일 기준 14일. 미션은 하루 1개씩 열림 (DAY n = 가입 n일째).
- 열린 미션은 기간 안에 언제든 완료 가능 (놓친 날 소급 가능 여부는 확정 필요).
- 칸 상태: `done`(완료) / `today`(오늘 열린 미션) / `open`(지난 날 열렸지만 미완료, 시안엔 없음) / `locked`(D-n 표시).
- 친구 초대·설문 등록 등 큰 보상은 부계정 악용 방지 조건 필요.

## 4. 화면

### 홈 (`designs/Home.dc.html`)
- 포인트 카드 바로 아래, 아이콘 4개 위에 웰컴 배너.
- 배너: 캐릭터 썸네일 / "웰컴 미션 DAY n" + TODAY 배지 / 미션 이름 / +P / 진행률 바(n/14).
- 포인트 카드 하단 문구: 웰컴 기간에만 "웰컴 미션으로 최대 450P 더 받을 수 있어요 ›" (라임색).
- 배너 상태:
  - 오늘 미션 남음: 흰 배경, TODAY 배지
  - 오늘 완료: Natural 50 배경, "웰컴 미션 DAY n 완료 · 내일 DAY n+1이 열려요"
  - 완주 또는 기간 종료: 배너 숨김

### 미션 메인 (`designs/Main.dc.html`)
- 전체 Blue 500 배경. 헤더(뒤로·제목·닫기) → 말풍선 "14일 동안 최대 450P" → 캐릭터 → "14일 웰컴 미션" → "미션 종료까지 N일" → MY 미션 현황 카드 → 미션 길(3열 지그재그, 15칸: 14 + 완주 보상) → 안내 문구 → "오늘 하루 보지 않기".
- 칸 지름 92px, 행 간격 160px, 길 두께 22px.
- 가입 직후·매일 첫 접속 때 전체 화면으로 노출 ("오늘 하루 보지 않기" 지원).

### 미션 상세 바텀시트 (`designs/Sheet.dc.html`)
- TODAY 칸 탭 → 바텀시트. DAY·카테고리 배지, 제목, 설명, 3단계 안내, 보상, CTA(해당 기능으로 이동), "나중에 할게요".

### 미션 완료 팝업 (`designs/Complete.dc.html`)
- 미션 완료 이벤트 시 노출. 캐릭터 + "DAY n 완료" 배지, "+nP 적립됐어요", 진행률, 내일 열리는 미션 미리보기, 확인.
