# 옛썰 온보딩(첫 화면 → 가입 → 첫 경험) – 개발 핸드오프

`designs/` 의 `.dc.html` 은 디자인 시안 원본이에요. 레이아웃·색·문구·움직임 참고용이고 그대로 실행되는 코드는 아니에요. 우리 앱(Expo) 스택과 기존 컴포넌트에 맞게 다시 구현해 주세요.
- 학교(중앙대), 닉네임(yessur), 숫자, 설문 제목은 모두 예시예요. 실제 데이터로 연결해 주세요.
- 시안 속 캐릭터 이미지(`/_blob/...`)는 앱에 이미 있는 마스코트 에셋(응원 포즈 / 학사모 포즈)으로 바꿔 주세요. **캐릭터는 첫 화면 · 환영 · 탭 말풍선 · 승인 대기에만** 써요. 다른 화면엔 넣지 않아요.
- 이모지 쓰지 않기.

## 0. 공통 스타일
| 토큰 | 값 | 쓰임 |
|---|---|---|
| 바탕 | `#FCFCFC` | 모든 화면 |
| 카드 | 흰색 + `1px #ECEEF3` + 부드러운 그림자, radius 22 | 기존 앱 카드 |
| 회색 상자 | `#F7F8FC` / `#EFF1F7` | 정보 묶음, 칩 바탕 |
| Blue 50 / 100 / 500 / 600 | `#F1F4FF` / `#E3E9FF` / `#3157D5` / `#2949B5` | 주 버튼, 강조 |
| Lime 100 / 500 / 800 | `#F0F8D5` / `#A3EA16` / `#506D23` | 포인트. **흰 바탕 위 초록 글자는 `#506D23`** (라임 `#A3EA16` 글자는 파란 바탕 위에서만) |
| 글자 | `#202A40` 본문 / `#545E73` 보조 | |

- 주 버튼: 높이 58, radius 18, Blue 500, 글자 17 굵게
- 입력 칸은 상자형(테두리 `#E2E5EE`, 포커스 시 Blue 500)
- 뒤로 버튼은 **'<' 모양 하나로 통일** (흰 원형 버튼 + 가운데 제목)
- 칩은 최소로
- 답이나 선택을 해도 **자동으로 다음 화면으로 넘어가지 않기**. 항상 버튼으로
- 모든 애니메이션은 `prefers-reduced-motion: reduce` 일 때 끔

## 흐름
```
① 첫 화면 → ② 회원 종류 ─ 학생 → ③ 약관 → ④ 학교 메일 → ⑤ 인증번호 → ⑥ 비밀번호·닉네임 → ⑦ 나에 대해
                         └ 단체 → (단체 정보 입력, 기존) → 승인 대기
⑦ 가입 완료 → ⑧ 가입 후 사용 안내(4장, 건너뛰기 가능) → ⑨ 환영 500P → 홈(웰컴 미션 1일차)
탭 처음 진입 → ⑩ 말풍선 / 첫 설문 응답 완료 → ⑪ 알림 허용 시트
마이 > 사용 안내 다시 보기 → 같은 4장 (X로 닫기)
```

## ① 첫 화면 (`Main.dc.html`)
- 위쪽 파란 반원(높이 590, 아래가 둥근 아치), 반투명 흰 원 장식 2개
- 제목 "대학생들의 진짜 생각,<br>**옛썰**에서 물어봐" (옛썰만 라임), 부제 "대학생끼리 설문을 주고받는 곳"
- 오른쪽 아래 캐릭터(위아래로 천천히 둥실)
- 왼쪽 대화창(200×236, 위·아래 페이드 마스크): 말풍선과 카드가 아래에서 하나씩 올라옴
  너는 어떻게 생각해? → 설문 카드(+30P) → (라임) +30P 받았어! → 이건 어때? → 밸런스 카드(짜장 58 / 짬뽕 42) → (라임) 나는 짜장파 → 골라 줘 카드
  - 13.5초 한 바퀴, **두 바퀴 돌고 멈춤**
- 버튼 위 "가입하면 **500P**를 바로 드려요"(500P는 `#506D23`), 버튼 "시작하기", 아래 "이미 계정이 있어요 · 로그인"

## ② 회원 종류 (`S1Type`) · 1/6
- 학생 / 단체 카드 2개 중 선택(선택 시 파란 테두리 + 체크). 아이콘·캐릭터 없음
- 학생 카드에만 "가입하면 500P" 작은 표시
- 선택 전엔 다음 비활성

## ③ 약관 (`S2Terms`) · 2/6
- **처음엔 전부 체크 해제**. "전체 동의" 누르면 모두 켜고/끔
- 필수 항목이 다 켜져야 다음 활성. 항목마다 "보기"

## ④ 학교 메일 (`S3Email`) · 3/6
- 제목 "학교 메일로 인증할게요", 설명 "학교 메일로 대학생인지 확인해요. 메일 주소는 다른 사람에게 보이지 않아요."
- 학교 상자(학교명 + 도메인 + "변경"), 아이디 입력 + 도메인 고정 표시, 버튼 "인증번호 보내기"

## ⑤ 인증번호 (`S4Code`) · 4/6
- 6칸 입력(한 칸씩 자동 이동), 남은 시간(5분) 카운트다운, "다시 보내기", "메일이 안 오면 스팸함도 확인해 주세요."

## ⑥ 비밀번호·닉네임 (`S5Account`) · 5/6
- 비밀번호 / 비밀번호 확인(눈 버튼으로 보기). **확인 칸 placeholder 글자 간격 정상으로**
- 닉네임 + "커뮤니티에서 보여요. 나중에 바꿀 수 있어요."
- 글자 링크 "친구한테 초대 코드 받았나요? ›" (누르면 입력칸 펼침)

## ⑦ 나에 대해 (`S6About`) · 6/6
- 맨 위 자물쇠 안내: 왜 묻는지 + 다른 사람에게 보이지 않음
- 전공 계열 칩(하나 선택), 과정(학부/대학원), 입학년도, 출생연도, 성별(남성/여성/선택 안 함)
- 버튼 "가입 완료" → **⑧ 사용 안내**

## ⑧ 가입 후 사용 안내 (`SignupGuide`) / 마이 › 다시 보기 (`MyReGuide`)
같은 4장짜리 화면. 다른 점은 위 오른쪽과 마지막 버튼뿐
| | 위 오른쪽 | 마지막 장 버튼 | 끝나면 |
|---|---|---|---|
| 가입 직후 | 글자 "건너뛰기" | "시작하기" | ⑨ 환영 |
| 마이 다시 보기 | X | "확인" | 마이로 돌아감 |

구성: 위 "n / 4", 가운데 그림(위쪽 약 420px), 아래 제목 2줄 + 설명, 점 표시(현재 장은 길게), 버튼 "다음"
- **장마다 들어오는 방식이 달라요**: 1장 아래에서 올라옴 / 2장 오른쪽에서 밀려옴 / 3장 작게 시작해서 커짐 / 4장 살짝 떠오름(페이드)
- **각 장 움직임은 약 3초 안에 끝나요** (장끼리 속도 맞추기)

1. **답하면 포인트가 쌓여요** — 설문 하나에 10P~200P, 오늘의 질문은 매일 5P
   - 기울어진 카드 더미(뒤 라임·연보라, 앞 '오늘의 질문' 카드)가 차례로 놓임
   - +5P, +30P, +20P 라임 칩이 카드에서 튀어나와 위 "내 포인트" 알약으로 날아감(0.8초 간격). 들어갈 때마다 알약이 통통 튐, 숫자 1,180 → 1,235 카운트업
   - 끝에 "오늘 벌써 **+55P** 모았어요"
2. **모은 포인트로 내 설문을 올려요** — 학교 메일로 인증된 대학생들이 답해요
   - 기울어진 폰 화면 안: 내 설문 제목, 큰 숫자 18 → 24 "/ 30명 응답", 진행 바
   - "새로 온 응답" 목록이 0.5초마다 한 줄씩 늘어남(학과·학번 + 시간). 마지막 두 줄은 "방금"이고 파란 점
3. **다른 설문 결과도 볼 수 있어요** — 데이터 탭에서 계열·학년별로 나눠 보고, 첫 결과 보기는 무료
   - 결과 카드: 질문, 계열 칩(공학 선택), 도넛 0 → 73% 채움 + 오른쪽 세부 비율 3줄, 아래 "이것도 많이 봤어요" 2개
   - 카드 오른쪽 위에 라임 배지 "첫 결과 무료"(자물쇠 열림 아이콘)가 늦게 튀어나옴
4. **커뮤니티에서 같이 놀아요** — 밸런스 게임, 골라 줘, 옛썰대전까지
   - 골라 줘 카드(종강 파티 메뉴): 삼겹살(내 선택) 41 / 치킨 33 / 마라탕 26 막대가 0.15초 간격으로 참, 퍼센트는 막대 뒤에 나타남
   - 댓글 3개가 0.6초 간격으로 부드럽게 올라옴(프로필 원 + 학번 + 고른 쪽 배지 + 하트 수). 첫 댓글 하트가 눌려 빨갛게
     - 삼겹살(파랑 배지) "종강엔 무조건 고기죠" / 치킨(라임 배지) "치킨은 배달 되잖아요 ㅋㅋ" / 마라탕(`#FEF6E7`/`#93370D` 배지) "마라탕도 한 표 주세요"

## ⑨ 환영 (`Welcome`)
- 색종이, 캐릭터 + "+500P" 튀어나옴
- "yessur님, 반가워요!" / "가입 선물로 500P 드렸어요"
- 웰컴 미션 1일차 카드: "설문 하나 답해 보기 · 1분이면 끝나요 · 완료하면 +30P"
- 버튼 하나 "첫 미션 하러 가기"

## ⑩ 탭 말풍선 (`Tooltip`)
- 데이터·커뮤니티·마이 탭을 **처음 열 때 한 번만**. 화면 어둡게 + 카드 하나에 라임 테두리
- 캐릭터 말풍선 한 줄 (예: 데이터 "여기서 다른 설문 결과를 볼 수 있어! 첫 결과 보기는 무료야"), "아무 데나 눌러서 닫기"

## ⑪ 알림 허용 (`Notify`)
- 첫 설문 응답 완료 화면("응답 완료! +30P 받았어요") 위에 바텀 시트
- 연파랑 상자 안 종 아이콘(캐릭터 아님), "내일 오늘의 질문, 알려 드릴까요?"
- "이런 때만 알려 드려요": 오늘의 질문(하루 5P) / 내 설문 응답이 다 모였을 때 / 웰컴 미션 할 시간
- 알림 받기 → 그다음에 OS 권한 창 / 나중에

## 단체 · 승인 대기 (`OrgPending`)
- 학사모 캐릭터, "승인 신청을 받았어요", 단체 이름 + 상태 "확인 중", 버튼 "둘러보기"
- 승인까지 걸리는 시간은 아직 미정 → 정해지면 문구에 넣기
