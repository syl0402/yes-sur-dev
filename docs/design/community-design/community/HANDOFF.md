# 옛썰 커뮤니티 개선 – 개발 핸드오프

범위: 커뮤니티 목록(피드), 밸런스 상세, 월드컵 진행·우승·결과, 글쓰기, 밸런스 빈 상태·보기 입력.

`designs/` 의 `.dc.html` 은 디자인 시안 원본이에요. 레이아웃·색·문구·인터랙션 참고용이고 그대로 실행되는 코드는 아니에요. 우리 앱 스택과 기존 컴포넌트에 맞게 다시 구현해 주세요.
시안 속 이미지 경로(`/_blob/...`)는 캔버스 전용이라 `assets/cheer.png` 를 쓰면 돼요.
게시글·인원·퍼센트는 모두 예시 데이터예요.

글 종류는 지금 앱에 있는 것만: **밸런스 · 나만 그래? · 골라 줘 · 설문 홍보 · 월드컵(공식)**. 새 종류는 테스트 후로 미뤄요.

## 0. 디자인 토큰
| 토큰 | 값 | 쓰임 |
|---|---|---|
| Blue 50 / 100 / 200 / 300 | `#F1F4FF` / `#E3E9FF` / `#C7D2FF` / `#9FB2FF` | 연한 배경, 밸런스 A쪽 투표 전 |
| Blue 500 / 600 / 700 | `#3157D5` / `#2949B5` / `#203A91` | 내 편(A), 버튼, 강조 글자 |
| Lime 100 / 300 / 500 / 800 | `#F0F8D5` / `#D0EB83` / `#A3EA16` / `#506D23` | 밸런스 B쪽, 1위 칩 |
| Natural 50 / 100 / 200 / 300 | `#F7F8FC` / `#EFF1F7` / `#E2E5EE` / `#CDD2DF` | 화면 배경, 막대 트랙, 테두리 |
| Natural 700 / 900 | `#545E73` / `#202A40` | 보조 / 본문 텍스트, VS 배지 |
| 월드컵 배지 | `#FEF6E7` 배경 / `#93370D` 글자 | "월드컵 16강" |

공통 규칙
- **진한 색은 "내가 참여한 순간"에만.** 투표 전 카드는 연한 색이라 피드가 시끄럽지 않게.
- 밸런스 카드 사이에는 다른 글 3~4개 끼우기 (연달아 노출 X).
- 보기 고른 뒤 **자동으로 넘어가지 않음**.
- 모든 애니메이션은 `prefers-reduced-motion: reduce` 일 때 끔.

## ① 커뮤니티 목록 (`Main.dc.html`)
위에서부터
1. 헤더 "커뮤니티" + 검색
2. 배너 200px (오늘의 질문 등, 바로 답하기 칩, "1 / 4" 페이지 표시)
   - 자동 넘김 4~5초, 손가락 닿으면 멈춤, 오늘의 질문 미답변이면 첫 장 고정
3. 지금 HOT 가로 스크롤 (1위만 파랑 동그라미)
4. 종류 탭: 전체 · 밸런스 · 나만 그래? · 골라 줘 · 월드컵
5. 피드 카드 (아래 카드별 스펙)
6. 글쓰기 FAB

### 카드 공통
- 흰 카드, radius 20, padding 14/16, 카드 간격 12
- 맨 위 줄: 종류 배지 + "작성자 · 시간"
- 제목 15px / 900
- 맨 아래 줄: "n명 · 댓글 n" 12px 회색

### 밸런스 카드 (줄다리기, C안)
- 높이 56px 막대, radius 16, 왼쪽 A / 오른쪽 B 각각 버튼
- 투표 전: A `#E3E9FF`/글자 `#2949B5`, B `#F0F8D5`/글자 `#506D23`, 경계 50%, 가운데 흰 VS 배지(30px)
- 투표 후:
  - 경계가 A 비율 위치로 이동 (`width` 0.8s, `cubic-bezier(.34,1.4,.64,1)`), 화면에선 30~70% 사이로 제한해 양쪽 글자 보이게
  - **내 편만 진한 색** (A `#3157D5`/흰 글자, B `#A3EA16`/`#202A40`), 상대편은 연한 색 유지
  - 퍼센트 숫자 pop (0.45s 딜레이), VS 배지 남색+라임 글자로 바뀌며 흔들림
  - 아래 문구: "○○파가 n%p 앞서는 중"
- 카드 탭(막대 외 영역) → ② 상세

### 밸런스 0명일 때 (`BalanceFix.dc.html` 1번)
- 캐릭터 안내 상자 **삭제**. 막대를 그대로 50:50 연한 색으로 보여주고 바로 투표 가능
- 아래 문구: "아직 아무도 안 골랐어요 · 첫 표를 던져 보세요"
- 첫 표 후: 내 편 100%, 막대는 72%까지만, 문구 "첫 번째로 편을 정했어요!"

### 나만 그래? 카드
- 버튼 2개 가로: "나도 그래" (Blue 50 배경) / "나는 아니야" (Natural 100)
- 누르면 버튼 안이 비율만큼 채워짐 + 퍼센트 표시, 내 선택 쪽 채움 색이 조금 진함

### 골라 줘 카드
- 보기 세로 목록 (44px, 테두리 `#E2E5EE`)
- 누르면:
  - 내 보기: 체크 아이콘 pop, 테두리 Blue 500, 굵게, 채움 `#C7D2FF`
  - 나머지: 채움 `#EFF1F7`
  - 막대가 위에서부터 0.08s 간격으로 차오름
  - 최다 득표 보기에 라임 "1위" 칩
  - **순서는 다시 정렬하지 않음**
- 보기 5개면 피드에선 3개까지 + "보기 n개 더"

### 월드컵 카드 (순위표 미리보기, C안)
- 배지 "월드컵 16강", 작성자 "옛썰 공식"
- 1~3위 행: 순위 동그라미(1위 라임), 이름, 승률 막대(1위 Blue 500, 나머지 Blue 300), 퍼센트
- "1:1 승률 · n명 참여 · 댓글 n"
- 버튼(연한 파랑 44px): "내 1위는 다를까? 해보기 (약 1분)" → ⑤ 월드컵 진행
- 이름은 "월드컵" 그대로 (시즌 행사 때만 "옛썰대전" 같은 이름)

### 설문 홍보 카드
- 본문 한 줄 + 설문 미니 카드(제목, "n문항 · 약 n분", 포인트 칩)

## ② 밸런스 상세 (`Vote.dc.html`)
- 헤더: 뒤로 / 공유 / 더보기(신고)
- 배지, 작성자(공식 체크), 제목, 설명
- **큰 줄다리기 막대** 72px: 위에 "광역버스파 / 지옥철파", 내 편 진한 색 + 큰 퍼센트 + "내 선택" 칩, 상대편 연한 색. 진입 시 50%에서 실제 비율로 이동
- 막대 아래 두 보기의 원래 긴 문장 (좌/우 정렬), "○○파가 n%p 앞서는 중 · n명 참여"
- 그룹별로 보기: 계열/학년/성별/나이대 칩 → 보기 칩 → "'보기'를 고른 비율" 그룹 막대(큰 순, 최고 Blue 500, 최저 Blue 300), 점선 아래 "전체 n%", 10명 미만 그룹 흐리게 + 안내
- 댓글: 익명 번호 + 내가 고른 편 배지, 글쓴이·공식 배지, 좋아요·답글은 아래 한 줄, 답글은 들여쓰기
- 하단 고정 댓글 입력 (익명 토글)

`BalanceC.dc.html` 은 같은 줄다리기의 큰 단독 버전 (HOT 영역 등에 크게 쓸 때 참고).

## ③ 월드컵 결과 (`Worldcup.dc.html`)
- 시상대 2·1·3 (1위 라임), 승률 표기
- **진입 애니메이션**: 시상대 3위→2위→1위 순서로 아래에서 솟음(`scaleY`, origin bottom), 이름 페이드인, 트로피 pop, 그다음 전체 순위 막대가 위에서부터 차례로 채워짐. 전체 2초 안
- 결과 화면엔 꽃가루 없음 (⑥ 우승 화면에만)
- 전체 순위 4위~ ("16위까지 모두 보기"), 그룹별 1위(10명 넘는 그룹만), 댓글 링크
- 하단: 다시 하기 / 결과 공유, "다시 하기는 결과에 반영되지 않아요"

## ④ 글쓰기 (`Write.dc.html`)
- 종류 칩: 밸런스 / 나만 그래? / 골라 줘 / 설문 홍보 + 종류별 힌트 한 줄
- 질문 입력은 **박스형** (밑줄형 X), 40자
- 밸런스 보기: A/B 네모 아이콘 **삭제**
  - 첫 칸 배경 `#F1F4FF` 테두리 `#C7D2FF` 글자 `#203A91`, 둘째 칸 배경 `#F0F8D5` 테두리 `#D0EB83` 글자 `#506D23`, 높이 56, 굵게
  - 두 칸 사이 오른쪽에 흰 VS 배지 걸침
  - placeholder "첫 번째 편 (예: …)" / "두 번째 편 (예: …)", 각 12자 + 글자 수 표시 (`BalanceFix.dc.html` 2번)
- 나만 그래?: 보기 자동("나도 그래 / 나는 아니야"), 질문만 입력
- 골라 줘: 보기 3~5개 박스 입력 + "보기 추가"
- 설문 홍보: 내 설문 선택 카드
- 익명으로 올리기 스위치

## ⑤ 월드컵 진행 (`WcPlay.dc.html`)
- 파랑/라임 대결 카드 2장, 고르면 체크 배지가 0.4초 보인 뒤 다음 대결로 넘어감 (월드컵은 빠른 진행이 재미라 예외적으로 자동 진행, 실수는 되돌리기로)
- 8칸 진행 바, 되돌리기
- 라운드 바뀔 때 "8강 진출" 같은 중간 화면

## ⑥ 월드컵 우승 (`WcWin.dc.html`)
- 꽃가루 + 마스코트 점프, 내 우승 후보
- "지금 순위 · 1:1 승률" 상위 3개, 결과 보기 / 공유
