## 1. 서비스 개요

**1. 문제 정의**

- 교내 월평균 설문 알림 약 40건, 실제 응답률 15.8% (2024.4 교내 조사, 표본 한계 있음)
- 학생 설문의 핵심 페인포인트: 어떤 툴도 응답자까지 제공하지 않음
- 유료 패널 대안 비용: 응답 1건 500~1,500원, 100명 약 15만 원부터

**2. 해결 방식**

- 학교 이메일 인증으로 **대학생만** 참여하는 폐쇄형 설문 생태계
- 응답 = 마일리지 적립 / 설문 등록·데이터 열람 = 마일리지 소진
- 가벼운 투표인 **취향·밸런스 탭**으로 매일 들어올 이유 제공

**3. 차별점**

- 학교·학년·전공 타깃팅 추가 비용 무료
- 성실도 검수로 불성실 응답 걸러냄
- 설문 제출 직후 전체 응답 분포와 내 위치를 보여주는 결과 리턴

### 3-2. 차감

| 이벤트 | 포인트 | 비고 |
| --- | --- | --- |
| 설문 등록 | 700P | 등록 버튼 클릭 시 차감 |
| 밸런스 질문 등록 | 0P | 무료 |
| 데이터 열람 · 1문항 설문 | 0P | 무료 |
| 데이터 열람 · 그 외 설문 | 500P | 한 번 열람하면 재열람 무료 |
| 불성실 응답 회수 | 지급액 전액 | 확정 후 신고·검수로 판별 시 |

### 3-3. 처리 규칙

1. 마일리지는 **현금·기프티콘 전환 불가**, Yes Sur 내부 서비스에서만 사용
2. 잔액은 별도 컬럼이 아닌 **포인트 원장(`point_ledger`) 합계**로 계산 → 모든 적립·차감은 원장 한 줄로 기록
3. 적립·차감은 클라이언트가 아닌 **서버 함수(Postgres RPC)** 에서만 실행
4. 상태: `pending`(예정) → `confirmed`(확정) / `rejected`(반려) / `revoked`(회수)
5. 잔액이 부족하면 차감 거부 (잔액이 음수가 될 수 없음)

> 💬 **미결정:** 응답 50명이 참여한 5분 미만 설문 1건 → 등록 700P 차감, 응답자에게 15,000P 지급 → 등록 1건당 약 14,300P 순증. 마일리지 과다 발행 우려 (「12. 미결정 사항」 #1)

## 7. 핵심 비즈니스 로직

### 7-1. 성실도 검수 (100점에서 감점)

| 규칙 | 기준 | 감점 |
| --- | --- | --- |
| 응답 속도 | 실제 소요시간 < 예상 소요시간의 30% | −40 |
| 주의 문항 | 지시 응답 문항 오답 | −50 |
| 일자형 응답 | 척도·객관식 연속 동일 선택이 전체의 80% 이상 (5문항 이상 설문) | −20 |
| 주관식 품질 | 5자 미만 또는 같은 문자 반복(ㅋㅋㅋ, asdf 등) | 문항당 −10 (최대 −30) |

| 점수 | 처리 |
| --- | --- |
| 70점 이상 | 즉시 확정 지급 |
| 50~69점 | 예정 상태 → 등록자 검수, 72시간 미처리 시 자동 확정 |
| 50점 미만 | 반려, 사유 고지 |

> 감점 수치는 제안값. `point_rules`처럼 설정값으로 관리

### 7-2. 설문 응답 처리 순서 (서버 함수 1회 호출로 처리)

1. 응답 가능 여부 확인 (중복·본인 설문·마감·목표 수)
2. 답변 저장
3. 성실도 점수 계산
4. 지급액 계산 (구간별 기본 + 얼리버드)
5. 원장 기록 (confirmed / pending / rejected)
6. 결과 리턴용 집계 반환

### 7-3. 소요시간 구간

- 1문항 / 5분 미만 / 5~15분 / 15분 이상 → 지급 마일리지 자동 결정
- 등록자가 지급액을 직접 바꿀 수 없음 (공정성)

### 7-4. 공개 범위

- 전체: 모든 인증 회원 열람 가능
- 교내: 같은 학교 회원만
- 비공개: 등록자만, 데이터 목록 미노출
