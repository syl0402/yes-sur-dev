# 옛썰 개발 보고 ④ 기초 디자인 적용

> 2026-10-31 · 개발파트 · **2, 4번을 확인해 주시고 5번에 의견을 적어 주세요.**
> 처리 여부 표시: ✅ 반영/확정 · 🔄 진행 중 · ❌ 반영 안 함(이유 적기) · (빈칸) 아직 확인 전

## 요약

디자인팀 시안(로고·마스코트·화면 4장)을 바탕으로 **앱 전체 화면에 기초 디자인을 입혔습니다.** 아이폰 실기기로 모든 화면을 확인했습니다.

**[적용한 것]**
- **색:** 메인 블루 `#3157D5` · 서브 라임 `#B7E65A` · 텍스트 네이비 `#17233C` · 배경 `#F5F7FF`
- **글꼴:** Pretendard (무료, 상업 이용 가능). 폰 기종과 상관없이 같은 글자 모양
- **화면 모양:** 연한 파란 바탕 위에 둥근 흰 카드. 버튼은 화면 아래 고정
- **공통 부품:** 카드, 버튼 3종, 알약 모양 칩, 탭 전환, 상태 뱃지, 진행 막대, 선택지 카드, 숫자 카드 등
- 색과 글꼴은 **파일 한 곳에서만** 정해서, 디자인팀이 색을 바꾸면 앱 전체가 한 번에 바뀝니다

**[시안을 거의 그대로 따른 화면]**
- 홈: 파란 포인트 카드("이번 주 ○○P를 모았어요") + 바로가기 3칸 + 오늘의 질문 + 마감 임박 설문
- 설문 응답: 진행 카드("현재 문항 1/12") → 질문 카드 → 선택지 카드 → 아래 [이전]/[다음]
- 내 설문 관리(마이 탭): 진행 중·마감 뱃지, 응답 진행률 막대, 숫자 카드, [결과 보기]

**[아직 임시]** 앱 아이콘, 시작 화면, 로고 그림, 마스코트 그림, 로그인 전 첫 화면 → 4번 표의 파일을 받으면 교체합니다
