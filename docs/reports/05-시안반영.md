# 옛썰 개발 보고 ⑤ 디자인 시안 반영 (홈 · 설문 · 데이터 · 커뮤니티)

> 2026-11-10 · 개발파트 · **2, 3, 4번을 확인해 주시고 5번에 의견을 적어 주세요.**
> 처리 여부 표시: ✅ 반영/확정 · 🔄 진행 중 · ❌ 반영 안 함(이유 적기) · (빈칸) 아직 확인 전

## 1. 요약

디자인팀 피그마 시안과 새 컬러 시스템을 앱 전체에 반영했습니다. 안드로이드 테스트 폰에서 화면을 하나씩 확인했습니다.

**[컬러]** 새 컬러 시스템(Blue · Lime · Natural 단계)을 반영했습니다. 화면 바탕은 Natural 30, 라임은 #A3EA16입니다.

**[홈]**
- 위쪽: 로고 · 검색 · ☰ 메뉴
- 마스코트 포인트 카드, 바로가기 4칸, 빠른 탐색(카테고리 8칸, 캐릭터)
- 추천 설문(옆으로 넘기기), 최신 설문 & 마감 임박, 취향 밸런스 인기 투표

**[오늘의 질문]** 홈 카드를 없애고, 앱을 켤 때 뜨는 **팝업**으로 바꿨습니다. 답할 때까지 앱을 켤 때마다 한 번씩 뜨고, "오늘 그만 보기"로 그날은 끌 수 있습니다.

**[설문 · 데이터]** 제목(설문조사 · 데이터 열람), 카드 모양, 검색칸, 정렬 · 걸러 보기 버튼, 탭을 시안대로 바꿨습니다. 새로 쓰기 버튼은 연필 모양입니다.

**[커뮤니티]** 맨 위에 **자동으로 넘어가는 배너**(4초)를 넣었습니다.
- 순서는 ① 오늘의 질문 → ② CC 좋다 vs 별로다 → ③ 어디 학교가 제일 예뻐? → ④ 트렌드 리포트 예고입니다.
- 배너마다 가벼운 움직임이 있습니다(마스코트 둥실, 이미지 천천히 확대, 막대그래프 자라남).

**[☰ 메뉴]** 앱 이동과 안내(홈 · 검색 · 옛썰 소개 · 의견 보내기 · 제휴 문의 · 약관 · 로그아웃)를 담았습니다. 내 정보와 내 기록은 마이 탭에 둡니다(푸망 방식).

> 📷 스크린샷 자리: 홈 / 오늘의 질문 팝업 / 설문 탭 / 데이터 탭 / 커뮤니티 배너 / ☰ 메뉴

## 2. 시안과 달라진 부분 ⭐ (확인 부탁드려요)

| 시안 | 실제 앱 | 이유 | 처리 여부 |
| --- | --- | --- | --- |
| 빠른 탐색 5칸 (학업 · 생활 · 소비 · 취향 · 커뮤니티) | **8칸** (학업 · 진로·취업 · 생활 · 소비·브랜드 · 취향·문화 · 연애·관계 · 사회·이슈 · 기타), 한 줄 2칸 | 지금 설문 카테고리가 8개입니다. "커뮤니티" 카테고리는 11/2에 하단 탭 이름과 겹쳐 "기타"로 바꿨습니다 | |
| 설문 · 데이터 탭 카테고리 4개 | 위와 같은 8개 그대로 | 같은 이유 | |
| 설문 탭 걸러 보기에 "내 설문" 없음 | "내 설문" 버튼 유지 (아이콘 추가), 버튼 줄은 옆으로 넘기기 | 11/9 팀 피드백으로 넣은 기능입니다 | |
| 홈 "오늘의 질문" 카드 | 카드 대신 팝업 + 커뮤니티 배너 1장 | 디자인팀 제안을 반영했습니다. 팝업을 닫아도 커뮤니티 배너와 12시 알림으로 다시 들어갈 수 있습니다 | |
| 추천 설문 "지금 당신의 관심사에 맞는 설문" | "지금 참여하기 좋은 설문" (우리 학교 설문 → 마감 가까운 순) | 관심사를 받는 기능이 아직 없어 사실과 다른 문구가 되지 않게 했습니다 (3번 질문) | |
| "마감 임박 3시간 전" | "마감 3시간 전" | "3시간 전"이 이미 지났다는 뜻으로 읽힐 수 있습니다 | |
| 인기 투표 6줄, 파란 NEW | 최대 5줄, 연한 빨강 (N) | 커뮤니티 HOT 목록이 5개까지입니다. N 표시는 폰에서 보고 정했습니다 | |
| 칸 너비 · 여백이 조금씩 다름 (17px, 26px 등) | 4의 배수로 통일, 빠른 탐색 칸 너비 균등 | 화면 전체가 고르게 보이도록 정리했습니다 | |
| 글꼴 일부 Roboto · Inter | 모두 Pretendard | 앱 글꼴을 하나로 맞췄습니다 | |

## 3. 정해 주세요 (기획팀) ⭐

| 질문 | 개발 추천 | 답변 | 처리 여부 |
| --- | --- | --- | --- |
| **관심사 기반 추천 설문**: 관심사를 무엇으로(카테고리 / 태그), 언제(가입 때 / 마이 탭), 몇 개까지 받을지 | 출시 후. 조사 결과가 나오면 회원 정보에 관심사를 추가합니다 | | |
| **트렌드 리포트 예고 배너**: 날짜 없이 "곧 공개"로 했습니다. 문구 확인 부탁드려요 ("주간 인사이트 · 월간 리포트 곧 공개돼요") | 첫 리포트가 나오면 실제 리포트로 연결합니다 | | |
| **커뮤니티 배너 바꾸기**: 지금은 앱에 고정돼 있어서, 바꾸려면 개발팀이 업데이트해야 합니다 | 출시 후 운영자가 직접 바꿀 수 있는 관리 화면을 만듭니다 | | |
