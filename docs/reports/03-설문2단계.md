# 옛썰 개발 보고 ③ 설문 2단계 (만들기·결과·데이터 허브)

> 2026-10-30 · 개발파트 · **2, 3번을 확인해 주시고 5번에 의견을 적어 주세요.**
> 처리 여부 표시: ✅ 반영/확정 · 🔄 진행 중 · ❌ 반영 안 함(이유 적기) · (빈칸) 아직 확인 전

## 요약

이제 설문을 **만들고 → 응답을 모으고 → 결과를 보고 → 다른 사람의 결과를 열람**하는 흐름 전체가 동작합니다. 비공개 테스트(11/12)에 필요한 탈퇴·신고·약관도 갖췄습니다. 모두 아이폰 실기기에서 확인했습니다.

**[설문 만들기]**
- 4단계로 작성해요: 기본 정보 → 문항 → 설정 → 확인
- 문항 종류는 4가지예요: 하나 고르기 · 여러 개 고르기 · 1~5점 · 주관식
- 문항이 5개 이상이면 **확인용 문항**(성실 응답 확인)이 자동으로 1개 들어가요.
- 임시저장: 오른쪽 위 [임시저장]을 누르거나 자동으로 저장되고, 마이 탭 "임시저장한 설문"에서 이어서 쓸 수 있어요.
- 주최 표시: 단체는 "중앙대 경영학과 학생회 ✓"처럼 학교와 이름이 나오고, 학생은 "개인"으로만 나와요.

**[결과 보기] 등록자**
- 문항별 그래프, 응답 정보(통과율·평균 응답 시간·조사 기간), 핵심 요약 문장
- **나눠 보기:** 계열 · 학년 · 성별 · 나이대. 5명 미만 묶음은 숨겨요.
- 결과 공개 범위: 전체 / 우리 학교만 / 나만 보기 (등록 후에도 바꿀 수 있어요)
- [응답 마감하기]로 일찍 마감하면 못 받은 인원만큼 등록비를 돌려받아요.
- 다운로드: **원본 CSV**(응답 한 명 = 한 줄)와 **집계 CSV**. 엑셀에서 한글이 깨지지 않아요.

**[데이터 탭] 다른 사람의 결과**
- 마감되고 응답이 5개 이상인 공개 설문이 올라와요. 카테고리, 인기순·최신순·응답 많은 순, [✓ 인증 단체만] 필터가 있어요.
- 무료로 볼 수 있는 것: 설문 정보, 응답자 구성, 문항 목록. 내가 응답한 설문이면 **"내 답 비교"**(나와 같은 답을 고른 비율)도 무료예요.
- **100P 열람**: 전체 그래프·나눠 보기·요약·집계 CSV. 열람료의 40%(40P)는 등록자에게 가요.
- 무료로 열람되는 경우: 첫 열람 1회, 1문항 설문, 옛썰 공식 설문, 단체 계정
- [출처 복사]: 과제·보고서에 붙일 출처 문장을 복사해요.

**[마이 탭]** 포인트 내역 · 내가 올린 설문 · 임시저장한 설문 · **열람한 결과** · 내 정보(회원정보·비밀번호 변경·약관·로그아웃·**회원 탈퇴**)

**[안전 장치]**
- **신고:** 설문 아래 "이 설문 신고하기"를 누르면 돼요. 3명이 신고하면 자동으로 숨기고, 운영자가 확인해서 되살리거나 삭제해요.
- **회원 탈퇴:** 앱 안에서 바로 할 수 있어요(Google Play 필수). 남긴 응답은 누구인지 알 수 없게 통계에만 남아요.
- **약관:** 이용약관·개인정보처리방침·계정 삭제 안내를 노션에 게시했어요. 가입할 때 4개 항목에 동의해요.

**[아직 없음 → 3단계(~12/9)]** 밸런스 투표 탭, 디자인 반영, 성의 없는 응답을 걸러 내는 기능 보강

## 2. 기획과 달라진 부분 ⭐ (확인 부탁드려요)

| 기획서·지난 보고서 | 실제 구현 | 이유 | 처리 여부 |
| --- | --- | --- | --- |
| 등록비 700P 고정, 응답 보상 50~3,000P | **보상은 앱이 지급:** 1문항 10P · 5분 미만 30P · 5~15분 80P · 15분 이상 150P. **등록비 = 응답 1명당 가격 × 목표 인원** (1명당 5·15·40·75P). 예: 5분 미만 설문 30명 = 450P | 고정 등록비로는 300명짜리 설문도 700P라 포인트가 계속 불어나요(인플레이션). 인원만큼 내야 균형이 맞아요 | |
| 결과 열람 500P | **100P**, 그중 40P는 등록자에게 | 학생이 응답 몇 번으로 열람할 수 있어야 데이터 탭이 쓰여요. 등록자는 결과를 공개할수록 등록비를 돌려받아요 | |
| 인원·기간 연장 | **만들지 않음.** 일찍 마감하면 남은 인원 환불 | 연장은 포인트 계산과 화면이 복잡해져요. 필요하면 새 설문을 올리면 돼요 | |
| 확인용 문항을 틀리면 포인트 미지급 | 미지급 + **결과에서 빼고, 다시 응답할 수 있음** | 실수로 틀린 사람도 다시 참여할 수 있게 했어요 | |
| 회원정보: 학교·학과·입학년도 | **성별·출생연도 추가** (가입 때 필수, 성별은 "선택 안 함" 가능). 한 번 입력하면 앱에서 못 바꿈 | 성별·나이대별 결과가 데이터의 가치를 크게 높여요. 생년월일 대신 출생연도만 받아요(최소 수집) | |
| 결과는 학교별로도 비교 | **학교 비교는 하지 않음.** 계열·학년·성별·나이대만 | 학교끼리 비교되면 학벌 서열 문제가 생길 수 있어요 | |
| (기획에 없음) | **단체는 결과를 공개하는 조건으로 등록 무료** ("나만 보기" 불가, 테스트 기간) | 단체 연구가 데이터 허브의 신뢰도를 높여 줘요. 나중에 비공개는 유료로 (아래 Q14) | |
| (기획에 없음) | **신고 · 회원 탈퇴 · 약관** 추가 | Google Play 심사 필수 항목이에요 | |
| 약관은 기획팀 작성 (Q11) | **개발팀이 초안 작성**, 노션에 게시 | 테스트 일정에 맞추려고 먼저 썼어요. 출시 전 법률 검토를 권해요 | |
