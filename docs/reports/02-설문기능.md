# 옛썰 개발 보고 ② 설문 기능 (1단계: 참여하기)

> 2026-10-29 · 개발파트 · **2, 3번을 확인해 주시고 5번에 의견을 적어 주세요.**
> 처리 여부 표시: ✅ 반영/확정 · 🔄 진행 중 · ❌ 반영 안 함(이유 적기) · (빈칸) 아직 확인 전

## 요약

학생이 **설문을 찾고 → 응답하고 → 포인트를 받는** 흐름을 완성했습니다. 아이폰 실기기에서 동작을 확인했습니다.

**[화면 구성]**
- 하단 탭 5개: 홈 · 설문 · 밸런스 · 데이터 · 마이 (밸런스·데이터는 "준비 중")
- 홈: 내 포인트, [설문 참여·등록·데이터 열람] 버튼, 마감 임박 설문 5개

**[설문 참여]**
- 목록: 추천순(우리 학교 → 마감 임박 → 남은 자리 적은 순) 외 최신·마감 임박·보상 높은 순
- 필터: 카테고리(학업·생활·소비·취향·커뮤니티) · 소요시간 · 학교 범위
- 상세: 보상, 문항 수·소요시간, 마감, 남은 자리, 응답 대상
- 응답: 한 화면에 한 문항, 이전·다음, 중간에 나가면 확인 창, 제출 전 확인 창
- 완료: "+300P 적립!"과 내 포인트
- 같은 설문은 한 번만 응답·적립됩니다. 목표 인원이 차면 자동 마감됩니다.

**[마이 탭]** 닉네임·학교, 내 포인트, 포인트 내역(어떤 설문으로 받았는지 함께 표시), 로그아웃

**[아직 없음 → 2단계(~11/12)]** 설문 만들기, 결과 보기, 데이터 허브·다운로드, 성실도 검사

## 2. 기획과 달라진 부분 ⭐ (확인 부탁드려요)

| 기획서·와이어프레임 | 실제 구현 | 이유 | 처리 여부 |
| --- | --- | --- | --- |
| 설문 등록자가 보상을 고름 (150/200/250) | **소요시간에 따라 자동 지급**: 1문항 50P · 5분 미만 300P · 5~15분 1,000P · 15분 이상 3,000P. 등록 비용은 700P 고정 | 등록자가 보상을 정하면 보상을 등록자가 부담해야 하고 포인트 계산이 복잡해집니다. 등록자 추가 보상은 출시 후 검토 (Q1) | |
| 하단 탭이 화면마다 4~5개로 다름 | **5개로 통일** (홈·설문·밸런스·데이터·마이). 설문 등록은 홈·설문 탭 버튼, 지갑은 마이 탭 안 | 화면마다 메뉴가 달라지면 사용자가 헷갈립니다 | |
| 데이터 허브는 4단계(11/20~) | **2단계로 당김** (비공개 테스트 11/12 전) | 데이터 열람이 다른 설문 앱과의 핵심 차별점이라 테스트에서 꼭 확인해야 합니다 | |
| 다운로드 범위 미정 | 등록자: 내 설문 원본(개인정보 제외) · 열람자: 500P 열람 후 집계 결과만. 남의 설문 원본은 출시 후 | 남의 원본을 받을 수 있으면 개인 특정 위험이 커집니다 | |
| 응답 대상이 아닌 설문도 목록에 표시 | **목록에서 안 보임.** 결과 공개는 따로 정함 (예: "응답은 중앙대만, 결과는 전체 공개") | 참여할 수 없는 설문이 섞이면 목록이 쓸모없어집니다. 결과는 에타 시험정보처럼 누구나 볼 수 있게 할 수 있습니다 | |
| "참여한 설문" 목록 | 지금은 **포인트 내역**에 설문 이름으로 표시. 별도 목록은 2단계 결과 보기와 함께 | 지금은 응답하면 바로 적립되므로 포인트 내역이 곧 참여 내역입니다 | |
