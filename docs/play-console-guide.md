## 1. 심사관 계정 (앱 액세스)

심사관은 학교 메일이 없어 회원가입을 못 한다 → **이미 가입된 학생 계정의 메일·비밀번호**를 준다 (로그인은 비밀번호만 있으면 됨, 인증번호 없음).

- 추천: 개발자 학생 계정의 비밀번호를 **심사 전용으로 새로 바꿔서** 적기 (앱 → 마이 → 내 정보 → 비밀번호 변경)
- 포인트가 넉넉해야 설문 등록까지 볼 수 있다 (`dev_tools.sql` 2번으로 1,000P 넣기)
- ⚠️ 비밀번호는 Play Console에만 적는다. 이 문서·코드·채팅에 적지 않는다

Play Console 입력:
- 앱 액세스: **"일부 또는 모든 기능이 제한됨"** → 안내 추가
- 이름: `학생 계정` · 사용자 이름: (메일) · 비밀번호: (새 비밀번호)
- 기타 안내:
  > 대학교 이메일 인증으로 가입하는 대학생 전용 앱입니다. 심사용 학생 계정으로 로그인 화면에서 이메일·비밀번호를 입력하면 바로 이용할 수 있습니다. 설문 응답·등록, 데이터 탭, 커뮤니티, 마이 탭(회원 탈퇴 포함)을 확인할 수 있습니다.

| 항목 | 답 |
|---|---|

### 3-1. 콘텐츠 등급 설문
- 카테고리: **소셜 또는 커뮤니케이션** (이 둘이 없으면 "기타 모든 앱 유형")
- 폭력·성적 콘텐츠·욕설·약물·도박: 모두 **아니요**
- **사용자끼리 소통하거나 콘텐츠를 공유할 수 있나요? → 예** (커뮤니티 글·댓글, 설문)
  - 신고 기능 있음 (설문 신고, 커뮤니티 신고) · 운영자 검토
- 사용자 위치 공유: 아니요 · 디지털 상품 구매: 아니요

### 3-2. 데이터 보안
공통 답:
- 데이터를 수집하거나 공유하나요? **예**
- 전송 중 암호화? **예** (HTTPS)
- 사용자가 삭제를 요청할 수 있나요? **예** (앱 안 탈퇴 + 계정 삭제 주소)

수집하는 데이터 (✅ = 체크):

| 분류 | 항목 | 필수/선택 | 목적 | 공유 |
|---|---|---|---|---|
| 개인 정보 | ✅ 이메일 주소 (학교·단체 메일) | 필수 | 앱 기능, 계정 관리 | 아니요 |
| 개인 정보 | ✅ 이름 (제휴 문의 담당자만) | 선택 | 개발자 커뮤니케이션 | 아니요 |
| 개인 정보 | ✅ 전화번호 (보상 연락처 · 제휴 문의) | 선택 | 앱 기능, 개발자 커뮤니케이션 | **예** → 보상 연락처는 그 설문 작성자에게 전달 (사용자 동의 후) |
| 개인 정보 | ✅ 기타 정보 (학교, 전공 계열, 학년, 성별, 출생연도, 관심사·생활 정보) | 학교·전공 필수 / 나머지 선택 | 앱 기능, 맞춤 설정(맞춤 설문 추천), 분석(익명 통계) | 아니요 (결과는 개인을 알 수 없게 묶어서만) |
| 앱 활동 | ✅ 앱 상호작용 (응답·투표·출석) | 필수 | 앱 기능, 분석 | 아니요 |
| 앱 활동 | ✅ 기타 사용자 제작 콘텐츠 (설문, 응답, 글·댓글, 의견) | 필수 | 앱 기능 | 아니요 |
| 앱 정보 및 성능 | ✅ 비정상 종료 로그 · 진단 (Sentry) | 필수 | 분석 | 아니요 (서비스 제공업체 처리는 공유 아님) |
| 기기 또는 기타 ID | ✅ 기기 ID (푸시 알림 토큰) | 선택 | 앱 기능 | 아니요 |

수집 안 함: 위치, 금융 정보, 건강, 사진·동영상, 연락처, 캘린더, 웹 기록, 메시지, 오디오 파일

## 4. 스토어 등록정보 (기본 스토어 등록정보)

**앱 이름**: 옛썰

**간단한 설명** (80자 이내):
> 대학생끼리 설문을 올리고 답하며 포인트를 모으는 학교 인증 설문 앱

**자세한 설명**:
> 옛썰은 학교 이메일로 인증한 대학생만 쓰는 설문 앱이에요.
>
> ■ 설문 응답하고 포인트 받기
> 1~3분짜리 설문에 답하면 포인트가 바로 쌓여요. 모은 포인트로 내 설문을 올릴 수 있어요.
>
> ■ 내 설문 올리기
> 과제, 동아리, 졸업 논문 설문을 대학생에게 바로 물어보세요. 우리 학교 학생만 대상으로 할 수도 있어요. 목표 인원이 모이면 자동으로 마감돼요.
>
> ■ 데이터 허브
> 마감된 설문 결과를 개인을 알 수 없게 묶어서 보여 줘요. 다른 학생들은 어떻게 생각하는지 확인해 보세요.
>
> ■ 커뮤니티
> 오늘의 질문, 밸런스 게임, 월드컵으로 가볍게 참여하고 포인트도 받아요.
>
> ■ 안심하고 쓰는 설문
> 응답은 익명으로 통계에만 쓰이고, 주관식 원문과 개인별 답은 공개되지 않아요. 성의 없는 응답은 걸러 내서 믿을 수 있는 결과를 만들어요.
>
> ※ 포인트는 앱 안에서만 쓰며 현금이나 상품권으로 바꿀 수 없어요.

## 5. 비공개 테스트 트랙 → 검토 신청

1. 테스트 및 출시 → 테스트 → **비공개 테스트** → 트랙 관리 (기본 "Closed testing - Alpha")
2. **국가/지역**: 대한민국
3. **테스터**: 이메일 목록 만들기 → 테스터 **구글 계정 메일**(학교 메일 아님) 붙여넣기 → 저장
   - 의견 URL/이메일: 팀 메일
4. **새 버전 만들기** → AAB 업로드
   - Play 앱 서명: **"Google에서 앱 서명 키 관리"** 그대로 (EAS 키는 업로드 키가 됨)
   - 버전 이름: 1.0.1
   - 출시 노트 (ko-KR):
     > 비공개 테스트 첫 버전이에요. 설문 응답·등록, 데이터 허브, 커뮤니티, 14일 웰컴 미션을 써 보고 마이 탭 '의견 보내기'로 알려 주세요.
5. 다음 → 오류·경고 확인 → **"검토를 위해 전송"** (출시 개요 화면에서 한 번 더 눌러야 할 수 있음)
6. 검토 통과 후: 트랙의 **테스터 → "웹에서 참여" 링크**를 기획팀에 전달
